# RTOS MOC

> 上级：[[嵌入式开发 MOC]]

## 概览
- 实时操作系统与并发模型：任务调度、同步、内存管理与常见内核。

## 核心笔记
- 主流 RTOS：FreeRTOS、Zephyr、RT-Thread、ThreadX、嵌入式 Linux
- 调度：优先级抢占、时间片、Tick 与无 Tick 模式

## 派生 / 子主题
- 任务与线程模型
- 同步原语：信号量 / 互斥量 / 队列 / 事件组
- 内存管理：静态分配 vs 堆、内存池
- 中断与临界区
- 时间管理：延时、定时器、看门狗
