# 内存映射与地址布局

> 上级：[[嵌入式基础概念 MOC]]

## 概述
- 芯片把 **Flash、SRAM、外设寄存器** 统一编址到一段**物理地址空间**；CPU 复位后从**固定复位向量地址**取第一条指令。
- 看懂地址布局，是理解启动流程、链接脚本与裸机程序的前提。

## 关键要点

### 典型地址区域（因芯片而异）
| 区域 | 说明 |
|------|------|
| 复位 / 中断向量 | 复位后 CPU 取第一条指令处 |
| 片内 Flash | 常映射低地址，可 XIP（原地执行） |
| SRAM / TCM | 快速，做启动早期栈；SPL/FSBL 常在此运行 |
| DRAM (DDR) | 系统主存，**需先初始化**才能使用 |
| 外设寄存器 | MMIO，映射到固定地址段 |
| BootROM | 只读，常在高端或固定段 |

### 链接脚本与加载地址
- 链接脚本（`.ld`）定义各段（`.text` / `.data` / `.bss`）的 **VMA / LMA**。
- 裸机：代码按 Flash 运行地址链接；启动早期可能需**重定位**（`.data` 从 Flash 复制到 RAM、`.bss` 清零）。
- 多级引导：一级引导仅用片内 SRAM 运行，**初始化 DDR 后**才搬到 DRAM。

### 常见坑
- 未初始化 DDR 就访问 DRAM 地址 → 取指/取数失败、挂死。
- 位置无关代码（PIE）与固定地址的取舍。
- 内存对齐、cache 一致性与 DMA（需按 cacheline 处理）。
