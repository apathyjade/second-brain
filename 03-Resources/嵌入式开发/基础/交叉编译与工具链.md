# 交叉编译与工具链

> 上级：[[嵌入式基础概念 MOC]]

## 概述
- 在**一台架构（host，如 x86_64 PC）**上，编译出**另一种架构（target，如 riscv64 / arm）**可运行的代码。
- 核心是**交叉工具链**：编译器、汇编器、链接器（binutils）、C 库、调试器。

## 关键要点

### 三元组（target triple）
- 形如 `<arch>-<vendor>-<os>-<abi>`：
  - `arm-none-eabi` —— 裸机（无 OS）
  - `riscv64-linux-gnu` —— RISC-V Linux（glibc）
  - `riscv64gc-unknown-linux-gnu` —— Rust 的 RISC-V 目标
- ABI 决定浮点/寄存器约定（如 `-mabi=lp64d`）。

### 常用变量与工具
- `CROSS_COMPILE=<prefix>-` → 展开为 `$(CROSS_COMPILE)gcc` 等。
- `--sysroot=`：目标根文件系统的头文件与库位置。
- C 库选择：glibc（完整）、musl（轻量）、newlib（裸机）。

### 构建方式
- 手装：riscv-gnu-toolchain、（ARM 用）Arm GNU Toolchain。
- 自动生成：**crosstool-NG**；或由构建系统提供 SDK（Buildroot / Yocto）。
- Rust：`rustup target add <triple>` + `.cargo/config.toml` 指定链接器。

### 常见坑
- host 工具（如 `pkg-config`、`mkimage`）与 target 库混淆。
- 静态 vs 动态链接、sysroot 未对齐导致找不到库。
