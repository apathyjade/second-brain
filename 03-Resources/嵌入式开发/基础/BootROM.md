# BootROM

> 上级：[[嵌入式基础概念 MOC]]

## 概述
- SoC 内部**出厂固化、只读**的一段引导代码，是每次上电**第一个执行**的软件。
- 别名：Boot ROM、Mask ROM、iROM（三星/Exynos 语境）。存在于硅片内部，**不可修改、不可覆盖**。

## 关键要点

### 职责
1. 上电后做**最简初始化**（时钟、基本 IO、看门狗）。
2. 按**启动顺序**在候选介质中寻找"第一段可执行固件"（校验头部 / 校验和）。
3. 加载到片内 SRAM（或直接到 DRAM，视设计），移交控制权。
4. 当前介质失败 → 尝试下一介质；全部失败 → 进入**恢复 / 下载模式**。

### 启动介质选择
- 由 **strap 引脚 / efuse / BOOT 按键**决定顺序，或强制某一介质。
- 典型顺序（因 SoC 而异，**以芯片手册为准**）：USB 下载 → SD → eMMC → SPI-NOR。
- 例：Allwinner = FEL、瑞芯微 = MaskROM、STM32 = 系统 Bootloader（DFU）。

### 恢复模式（救砖关键）
- 由于 BootROM 不可破坏，即使板载引导固件损坏，也能通过固化接口**重新烧录**。
- 常用载体：USB（批量/DFU/FEL/MaskROM）、UART（部分芯片）、专用工具。

### 边界与误解
- **不能覆盖 BootROM**；但**可以覆盖它所加载的下一段**（[[引导加载器（Bootloader）]] / [[固件（Firmware）]]）。
- 是否强制验签，取决于是否启用**安全启动**；未启用时下一段可自由替换。
