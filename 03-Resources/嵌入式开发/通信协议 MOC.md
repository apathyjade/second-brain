# 通信协议 MOC

> 上级：[[嵌入式开发 MOC]]

## 概览
- 板内、板间与无线通信协议：物理层特性、帧格式、时序与常见坑。

## 核心笔记
- 板内总线：I2C、SPI、UART、I2S
- 现场总线：CAN / CAN-FD、Modbus、RS485
- 无线：BLE、WiFi、LoRa、Zigbee、NB-IoT
- 应用层：MQTT、CoAP、HTTP

## 派生 / 子主题
- 时序与电气特性（电平、终端电阻、上拉）
- 协议帧格式与校验
- 主从 / 多主架构
- 调试与抓包（逻辑分析仪、总线分析仪）
